# First-draft choice: triage or directory?

Brief: among 30 projects, find the urgent ones and their owners. Same brief, model and data; two first drafts. [A: attention first](triage-a.png) was generated with UI UX Pro Max; [B: directory first](triage-b.png) with this pack's v0.18.0. The product owner preferred A overall in a blind comparison. This is one preference, not a timed usability result.

In A, three urgent names and their owners form a readable group before the search tools. Restrained warning color connects urgency to those records, while quieter owner labels answer the second question. The summary is context; the named records are the answer. In B, the banner gives a count and two owner names, but you must look past filters to connect each project to its owner. Both included the right records; their order and emphasis differed.

Transfer the reasoning, not the cards or colors. For a known-item lookup across the whole directory, B's prominent search and aligned columns could be preferable. For a new brief, ask what the first view lets the user decide, then tune component, typography and color together to support that decision. Check the actual mobile view: stacking every desktop control first can bury the answer again.
